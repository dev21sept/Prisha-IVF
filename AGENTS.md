# Prisha IVF Platform

This project is built with **Pure React.js (Vite + React Router + Tailwind CSS)** and an **Express.js API Server**.

## Structure
- `src/`: Pure React application with `.jsx` and `.js` components, pages, and context.
- `server/`: Express API backend with JSON persistence and email outbox logging.
- `public/`: Assets, images, and videos.
